## 1. Што е производот

B2B2C платформа за настани (прво свадби) во Македонија:

- **Ресторан/сала (venue)** — купува пакет, отвора профил, ги води салите, масите, настаните, резервациите, менијата. Му дава на парот бесплатен START пакет.
- **Пар/славеник (couple)** — добива најава од ресторанот; прави гости, покана, распоред, мени, агенда, локации, албум.
- **Гости** — без сметка; отвораат линк/QR: покана, RSVP, „Каде седам?“, агенда, локации, фотографии, честитки.
- **Сопственик на продуктот (admin)** — надзор и поддршка, нивоа/пакети, отклучува бенефиции по сала и по настан.

Клучна порака од клиентот (Viber): *„Битно е сега здрави темели за да може да биде стабилна за надградување со многу подменија и клиенти, оти ќе е директно поврзана со работењето на локалите за идни резервации.“*

Пилот клиенти: **Leona Lux / Леона Лух (Радовиш, 2 сали)**, Diamond Hotel & Restaurant (Радовиш). Демо сметка во Cloud: kadesum@leonalux.com → сала „Kade Sum“.

## 2. Стек и правила (важат за сите сесии)

- Next.js 16.3 (App Router, `proxy.ts`), React 19, TypeScript, Tailwind + `app/venue/panel.css`, Supabase (Postgres + RLS + Auth + Storage), Vercel (dub1), Resend (email, опционално), Sentry (опционално).
- Node 22: `export PATH=/opt/homebrew/opt/node@22/bin:$PATH`.
- **Dev = Supabase Cloud** (`.env.local`, проект kade-sum). **Локален Docker Supabase = само за тестови** (`.env.test.local`, `node scripts/write-test-env.mjs`). Тестовите никогаш не смеат да го гаѓаат Cloud. Без `supabase db reset` освен локално; избегнувај reset додека други сесии ја користат локалната база (користи `npx supabase migration up --local`).
- **Claude не прави git commit/push.** По секоја завршена задача дај му на корисникот `git add … && git commit -m "…"` — **без Co-Authored-By**.
- Не менувај `CLAUDE.md`. Тајни (клучеви, лозинки) никогаш во чат или git. Не правиш `db push` на prod, не додаваш тајни во Vercel — тоа го прави сопственикот.
- Миграции: секоја сесија има **свој опсег на броеви** (дел 7) — никогаш не менувај постоечка миграција.
- Explicit grants (од 0031): нови табели `enable row level security` + `revoke … from anon, authenticated` + експлицитни grant-ови; нови функции `revoke all … from public`; `security definer` секогаш со `set search_path = public, extensions, pg_temp`. Секоја нова табела во `tests/supabase/rls_guard.test.ts`, секоја нова колона во `tests/supabase/privacy-classification.ts`.
- API рути: `withCoupleEvent` / `withPublic` од `lib/api/handler.ts`, zod шеми, само намерни пораки кон корисникот.
- UI текст на **македонски**. Mobile-first за сè што гледаат гостите.
- Гејтови пред секој commit: `npm run typecheck && npm run lint && npm run test:unit`, за DB работа `npx vitest run -c vitest.db.config.ts <files>`, на крај на фаза `npm run test:db && npx playwright test`.
- Hub (GoDevLab): по секоја задача progress update; за листа на работа — креирај task-ови и означувај ги `done` веднаш кога се верификувани (упатство во `CLAUDE.md`).
